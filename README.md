SET UP :
  - 2 Controller (Gamepad)
  - Input :
      - Left Stick -> player movement / car direction
      - North Button -> Enter/Exit car
      - South Button -> jump (car/jump)
      - Left Trigger -> car break / reverse
      - Right Trigger -> car acceleration
   
  - Car Details :
        - Controls are Split in two section :
            - Wheel (left side): can control direction
            - Pedals (right side): can control acceleration / reverse / break
            - to jump -> both player must press the input at the same time.
